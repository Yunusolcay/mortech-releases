# Mortech Client

**Download [MortechLauncher.exe](https://github.com/Yunusolcay/mortech-releases/releases/download/channel-stable/MortechLauncher.exe) and run it.**

The launcher installs Mortech Client into `%LOCALAPPDATA%\Mortech Client` (no administrator rights), keeps it up
to date and starts the game. Updates download only the files that changed. Mortech Client plays on Ultima Online
shards with your own Ultima Online Classic installation (map, hues, texts and sounds are read from it; none of
those files are distributed here).

- Windows SmartScreen may warn that the exe is from an unknown publisher (it is not code-signed): choose
  "More info" > "Run anyway".
- Test builds: `Settings > Update channel > Dev` in the launcher, or the
  [dev channel launcher](https://github.com/Yunusolcay/mortech-releases/releases/download/channel-dev/MortechLauncher.exe).
- Manual install without the launcher: the `MortechClient-<version>-win-x64.zip` of a version release.

This repository holds only built files (signed manifests, game files, the launcher); the game's source is not here.
